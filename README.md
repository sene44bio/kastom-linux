# Kastom Linux — Cyberpunk Edition

Кастомное рабочее окружение в стиле Cyberpunk Deck, развернутое поверх Linux Mint (Cinnamon / Muffin X11).

Сборка включает кинематографичную последовательность старта системы, набор легковесных прозрачных HUD-виджетов, нижний аудио-визуализатор, встроенный терминал с защитой от сворачивания и скрипты управления оконными слоями X11.

---

## Компоненты системы

### 1. Последовательность загрузки (Startup Sequence)
* **eDEX-UI Boot Screen:** Запуск терминального интерфейса инициализации с аудио-эффектами при входе в систему.
* **Экран приветствия (`opt/cyber-welcome/`):** Графическое окно авторизации оператора на базе Python и PyQt.
* **Защита от цикличного запуска:** В `launch_full_intro.sh` реализован механизм через lockfile (`/tmp/cyber_intro.lock`), исключающий повторный запуск анимации интро при обычном перезапуске оконного менеджера.

### 2. Центральный дек (`hud_center.py`)
* Цифровые часы, календарь и индикатор статуса системы.
* Медиаплеер с отображением текущего трека, таймингов, интерактивным прогресс-баром и кнопками управления.
* Интеграция через MPRIS / D-Bus для захвата данных из локальных плееров и браузера.

### 3. Метео-телеметрия (`hud_weather.py`)
* Виджет погоды с пиксельным маскотом и карточками почасового прогноза на 5 часов вперед.
* Прямой опрос API `wttr.in` в формате JSON через неблокирующий поток `QThread` (таймаут 6 секунд, интервал обновления 15 минут).
* Отсутствие внешних тяжелых библиотек парсинга.

### 4. Системный монитор (Conky)
* Панель телеметрии: статус оператора, время непрерывной работы (uptime).
* Поядерный мониторинг процессора с графическими шкалами загрузки.
* Мониторинг оперативной памяти, свободного места на накопителе и скорости сетевых интерфейсов (DL/UL).

### 5. Аудио-визуализатор (Cava Dock)
* Спектральный анализатор частот над панелью задач.
* Построен на связке Cava и кастомного PyQt-оверлея без рамок и теней.

### 6. Встроенный терминал рабочего стола (`embedded_terminal.sh`)
* Прозрачный терминал на базе `gnome-terminal` с выводом системной информации.
* Окно привязано к слою рабочего стола через X11-атомы `_NET_WM_WINDOW_TYPE_DOCK` и `_NET_WM_STATE_BELOW`.
* Терминал не скрывается при сочетании клавиш Super + D («Показать рабочий стол») и остается полностью интерактивным для ввода команд.

```text
kastom-linux/
├── config/
│   ├── autostart/                  # Автозапуск (.desktop файлы)
│   ├── cava/                       # Конфигурация спектрограммы Cava
│   ├── conky/                      # Конфигурация Conky
│   ├── hud/                        # Скрипты HUD-виджетов и демоны слоев
│   ├── startup-sfx/                # Скрипты запуска интро со звуком
│   └── autostart_desktop_hud.sh    # Главный скрипт инициализации окружения
├── opt/
│   └── cyber-welcome/              # Скрипты экрана авторизации
├── wallpapers/                     # Обои рабочего стола с неоновым логотипом
├── set_wallpaper.sh                # Скрипт установки обоев
